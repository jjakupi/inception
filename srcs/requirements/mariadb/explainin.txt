What is /var/lib/apt/lists/?

When you run:apt-get update
👉 Debian downloads package lists (indexes) and stores them here:
/var/lib/apt/lists/
These files are:
- NOT needed after installation
- Only used during install
 Without removing them

Your image will:- Be bigger,Contain useless files

Yes — I mean inside the MariaDB container.

Even if the container is mainly for MariaDB, it can still contain several programs/tools installed from the MariaDB package.

For example inside the MariaDB container you can have:

mysqld / mariadbd     = the MariaDB server daemon
mysql                 = command-line client
mysqladmin            = admin/check tool
mysql_install_db      = initialization tool
mysqld_safe           = helper script to start MariaDB safely

So when I say “programs inside the same container”, I mean things like:

mysql client → talks to → mariadbd server

Both can be inside the same MariaDB container.

Example:

docker exec -it mariadb bash
mysql -u root -p

Here you are inside the MariaDB container. The mysql client may connect to the MariaDB server through:

/run/mysqld/mysqld.sock

because both are local, inside the same container.
