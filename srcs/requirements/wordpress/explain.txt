Why /var/www/html:This is the classic Linux folder where website files are stored.
NGINX receives request
NGINX sees .php file
NGINX sends it to PHP-FPM
PHP-FPM executes it
NGINX sends result to browser

PHP-FPM is the program that runs PHP code.

wp-config.php is the main WordPress configuration file.
It tells WordPress:
What database should I use?
What username?
What password?
Where is the database server?

'sed' : is a Linux tool used to edit text.
'sed -i':means:edit the file directly
s|listen = /run/php/php7.4-fpm.sock|listen = 9000| ==substitute listen /run... with listen 9000
/etc/php/7.4/fpm/pool.d/www.conf This is the file being edited.
Why do we need this:RUN sed -i 's|listen = /run/php/php7.4-fpm.sock|listen = 9000|' /etc/php/7.4/fpm/pool.d/www.conf
Because NGINX is in a different container.
If PHP-FPM listens on:
/run/php/php7.4-fpm.sock
that socket exists only inside the WordPress container.
A socket is a communication point between two programs.

WP-CLI:WordPress Command Line Interface,It is a command-line tool to control WordPress.

So WordPress can reach it with the hostname:mariadb
Not localhost.Why not localhost:
Because WordPress and MariaDB are in different containers.
